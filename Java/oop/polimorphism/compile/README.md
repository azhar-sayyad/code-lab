# Compile-Time Polymorphism

Compile-time polymorphism is method overloading: same method name, different parameter list.

## Files
- `Calculator.java`
- `Demo.java`

## Run
```bash
javac src/oops/polimorphism/compile/*.java
java -cp src oops.polimorphism.compile.Demo
```
