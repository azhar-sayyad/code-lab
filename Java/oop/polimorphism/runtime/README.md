# Run-Time Polymorphism

Run-time polymorphism is method overriding with parent reference and child objects.
The JVM decides which overridden method runs at runtime.

## Files
- `Notification.java`
- `EmailNotification.java`
- `SmsNotification.java`
- `AppPushNotification.java`
- `Demo.java`

## Run
```bash
javac src/oops/polimorphism/runtime/*.java
java -cp src oops.polimorphism.runtime.Demo
```
