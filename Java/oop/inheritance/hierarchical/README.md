# Hierarchical Inheritance

In hierarchical inheritance, multiple child classes inherit from one parent class.

## Structure
- Parent: `Employee`
- Children: `Developer`, `Designer`

## Run
```bash
javac src/oops/inheritance/hierarchical/*.java
java -cp src oops.inheritance.hierarchical.Demo
```

Developer writes backend code.
Company: TechNova
