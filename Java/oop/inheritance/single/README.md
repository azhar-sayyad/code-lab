# Single Inheritance

In single inheritance, one child class inherits from one parent class.

## Classes
- `Vehicle` (parent)
- `Car` (child extends `Vehicle`)

## Run
```bash
javac src/oops/inheritance/single/*.java
java -cp src oops.inheritance.single.Car
```

```text
Toyota vehicle started.
Model: Corolla
```
