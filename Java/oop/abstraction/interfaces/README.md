# Abstraction Using Interface

This example uses an interface as a contract with multiple implementations.

## Files
- `PaymentGateway.java` (interface)
- `UpiPayment.java`
- `CardPayment.java`
- `NetBankingPayment.java`
- `Demo.java`

## Run
```bash
javac src/oops/abstraction/interfaces/*.java
java -cp src oops.abstraction.interfaces.Demo
```
