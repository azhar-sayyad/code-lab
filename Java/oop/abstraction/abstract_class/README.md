# Abstraction Using Abstract Class

This example uses an abstract class to define shared behavior and enforce required methods.

## Files
- `Appliance.java` (abstract class)
- `WashingMachine.java`
- `Microwave.java`
- `Demo.java`

## Run
```bash
javac src/oops/abstraction/abstract_class/*.java
java -cp src oops.abstraction.abstract_class.Demo
```
