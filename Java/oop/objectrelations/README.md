# Object Relations in Java

This location is recommended: `src/oops/objectrelations/`.

## Structure
- `association/` -> interaction without ownership
- `aggregation/` -> has-a relation with external object reference
- `composition/` -> has-a relation with internal object creation/ownership
- `ObjectRelations.md` -> comparison of all three
- `AggregationVsComposition.md` -> focused comparison of two has-a relations
