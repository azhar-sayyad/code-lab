# Design Principles (Java)

This section contains beginner-friendly examples for core software design principles.

## Folders
- `DRY/` - Don't Repeat Yourself
- `KISS/` - Keep It Simple, Stupid
- `YAGNI/` - You Aren't Gonna Need It
- `SOLID/` - five SOLID principles with separate examples

Suggested order: `KISS -> DRY -> YAGNI -> SOLID`.
