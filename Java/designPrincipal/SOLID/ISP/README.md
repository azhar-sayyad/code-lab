# ISP - Interface Segregation Principle

Clients should not be forced to depend on methods they do not use.

Here, print and scan are split into separate interfaces.
A basic printer implements only printing.

## Run
```bash
javac src/designPrincipal/SOLID/ISP/ISPDemo.java
java -cp src designPrincipal.SOLID.ISP.ISPDemo
```
