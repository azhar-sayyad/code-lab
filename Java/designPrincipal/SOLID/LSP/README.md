# LSP - Liskov Substitution Principle

Child types should be usable anywhere the parent type is expected, without breaking behavior.

In this example, every `Notification` subtype works through the same `send()` contract.

## Run
```bash
javac src/designPrincipal/SOLID/LSP/LSPDemo.java
java -cp src designPrincipal.SOLID.LSP.LSPDemo
```
