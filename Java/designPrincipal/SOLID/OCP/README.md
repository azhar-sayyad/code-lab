# OCP - Open/Closed Principle

Software should be open for extension, closed for modification.

In this example, adding a new discount type only requires a new class.
Existing processor code does not change.

## Run
```bash
javac src/designPrincipal/SOLID/OCP/OCPDemo.java
java -cp src designPrincipal.SOLID.OCP.OCPDemo
```
