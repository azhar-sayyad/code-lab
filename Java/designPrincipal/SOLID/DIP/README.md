# DIP - Dependency Inversion Principle

High-level modules should depend on abstractions, not concrete classes.

In this example, `OrderService` depends on `MessageSender` interface,
so we can switch implementation without changing service logic.

## Run
```bash
javac src/designPrincipal/SOLID/DIP/DIPDemo.java
java -cp src designPrincipal.SOLID.DIP.DIPDemo
```
