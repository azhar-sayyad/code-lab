# SRP - Single Responsibility Principle

A class should have one reason to change.

In this example:
- `Invoice` handles invoice data only
- `InvoicePrinter` handles printing only

## Run
```bash
javac src/designPrincipal/SOLID/SRP/SRPDemo.java
java -cp src designPrincipal.SOLID.SRP.SRPDemo
```
