# YAGNI Principle

YAGNI means: **You Aren't Gonna Need It**.

Do not build features before they are required.
Write only what is needed now, and extend later when requirements are real.

## Example in This Folder
`YAGNIDemo.java` compares:
- premature support for multiple export types
- current requirement solved with one focused method

## Run
```bash
javac src/designPrincipal/YAGNI/YAGNIDemo.java
java -cp src designPrincipal.YAGNI.YAGNIDemo
```
