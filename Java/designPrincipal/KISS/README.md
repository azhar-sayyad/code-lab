# KISS Principle

KISS means: **Keep It Simple, Stupid**.

Prefer straightforward solutions over clever but hard-to-read logic.
Simple code is easier to debug, test, and maintain.

## Example in This Folder
`KISSDemo.java` compares:
- unnecessary complex grade calculation
- clean if-else based grade calculation

## Run
```bash
javac src/designPrincipal/KISS/KISSDemo.java
java -cp src designPrincipal.KISS.KISSDemo
```
